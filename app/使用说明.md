# Aria2 便携版 · 使用说明

一套免安装的 Windows 下载器：**aria2 后台引擎 + AriaNg 网页面板 + 浏览器扩展接管**。
用来替代 IDM 或浏览器自带下载，支持多线程加速、断点续传、直链 / 磁力 / 种子。

- 绿色版：解压即用，不写注册表（只创建桌面快捷方式）
- 整个文件夹可以随便移动、复制、删除
- 所有文件都在本地，不上传任何数据

---

## 一、安装（三步）

1. **解压**到任意目录，例如 `D:\Aria2`。
   - 不要放在 `C:\Program Files`（权限不足，配置写不进去）
   - 路径里尽量不要有空格
2. **双击 `install.bat`**。它会：
   - 生成一份随机 RPC 密钥
   - 按当前目录生成 `conf\aria2.conf`、`panel.bat`、`conf\panel-url.txt`
   - 生成 `Aria2-Explorer-配置.json`（给浏览器扩展用）
   - 在桌面创建「Aria2 下载器」和「Aria2 面板」两个快捷方式
3. **装浏览器扩展并导入配置**：
   - Edge：打开 `edge://extensions`，搜索并安装 **Aria2 Explorer**（作者 alexhua）
     - 商店直链：https://microsoftedge.microsoft.com/addons/detail/ngojgbdekanmijaphecgpmfoegoanffi
   - Chrome：应用商店搜 **Aria2 Explorer**
   - 安装后打开扩展的「选项」，找到 **导入/导出（Import/Export）**
   - 选择本目录下的 `Aria2-Explorer-配置.json` 导入
   - 导入后 RPC 地址、密钥就都配好了，不需要手填

## 二、日常使用

| 操作 | 方法 |
|---|---|
| 启动 | 双击桌面「Aria2 下载器」（后台启动引擎 + 打开面板） |
| 只开面板 | 双击桌面「Aria2 面板」 |
| 下载 | 直接在网页上点下载链接，扩展会把任务丢给 aria2 |
| 临时不接管 | 按 `Alt + A` 关闭自动拦截，再按一次恢复 |
| 看进度 | 点浏览器工具栏的 **A2E** 图标 → 打开面板 |
| 停止引擎 | 双击 `stop.bat` |
| 看日志 | 双击 `view-log.bat`（实时滚动） |

下载完成的文件默认在 **`安装目录\Downloads`**。

### 关于「为什么浏览器里看不到下载条」

这是接管式下载的正常表现：扩展拦下链接后直接交给后台 aria2，**浏览器自己并没有发起下载**，
所以 Edge/Chrome 的下载气泡、`edge://downloads` 里不会有记录。想看任务请用面板或扩展图标。

如果你确实需要浏览器原生下载（例如小文件想留个记录），按 `Alt + A` 临时关掉拦截即可。

## 三、目录结构

```
Aria2下载器\
├─ install.bat                安装（首次运行一次）
├─ start.bat                  启动引擎并打开面板（日常用这个）
├─ panel.bat                  只打开面板（安装后生成）
├─ stop.bat                   停止引擎
├─ view-log.bat               查看实时日志
├─ autostart-on.bat           设置开机后台自启
├─ autostart-off.bat          取消开机自启
├─ uninstall.bat              清理自启项与快捷方式
├─ daemon.vbs                 无窗口启动 aria2（被其它脚本调用）
├─ aria2c.exe                 aria2 引擎 1.37.0
├─ aria-ng\index.html         AriaNg 面板（离线单文件）
├─ conf\
│  ├─ aria2.conf              运行配置（安装时生成，可自己改）
│  ├─ aria2.conf.template     配置模板
│  ├─ aria2.session           任务队列（未完成的任务存在这里）
│  ├─ aria2.log               运行日志
│  └─ panel-url.txt           面板地址（含密钥）
├─ Downloads\                 下载目录
├─ Aria2-Explorer-配置.json   浏览器扩展的导入文件
├─ 使用说明.html / .md        本文档
└─ LICENSES\                  开源许可
```

## 四、常见问题

**1. 点了链接没反应？**
先看 `Downloads` 目录里文件是不是已经在长大——多数时候它正在后台下载，只是浏览器没有提示。
再双击 `view-log.bat`，能看到 `Download complete: ...` 就说明一切正常。

**2. 所有下载都失败，日志里是 `errorCode=1` + `unreachable network`？**
IPv6 造成的：机器有 IPv6 地址但没有 IPv6 出口（装过 VPN、Radmin、虚拟网卡等都算），
aria2 会先尝试 IPv6 连接，直接失败。新版配置里已默认写 `disable-ipv6=true`；
老配置请在 `conf\aria2.conf` 里补上这一行，然后 `stop.bat` → `start.bat`。

**3. 面板打开显示「认证失败」？**
说明密钥不匹配。重新运行一次 `install.bat`（会沿用原密钥并重写面板地址），
或直接双击 `panel.bat` 而不是手动打开 `aria-ng\index.html`。
手动打开时需要在设置里填：协议 `HTTP`、主机 `127.0.0.1`、端口 `6800`、密钥见 `conf\aria2.conf` 里的 `rpc-secret=`。

**4. 下载立刻失败，日志里是 `errorCode=18`？**
下载目录路径不合法，最常见的原因是**路径首尾带引号**（从资源管理器「复制为路径」粘进来的）。
在扩展设置里把「下载目录」改成不带引号的路径，或直接留空使用默认目录。

**5. 速度不如预期？**
- 单个服务器的带宽和限速是主要瓶颈，GitHub 之类的站点本来就慢
- 可以在 `conf\aria2.conf` 里调大 `split`、`max-connection-per-server`（默认各 16）
- 改完先 `stop.bat` 再 `start.bat`

**6. 想换下载目录？**
改 `conf\aria2.conf` 里的 `dir=` 那一行，然后重启。注意路径不要加引号。

**7. 换端口？**
改 `conf\aria2.conf` 里的 `rpc-listen-port=`，然后**重新运行一次 `install.bat`**——
它会沿用你改过的端口和原密钥，重写面板地址；浏览器扩展里的 RPC 地址也要同步改成新端口。

**8. 开机自启？**
双击 `autostart-on.bat`（只是往启动文件夹里放一个快捷方式，不写注册表）；取消用 `autostart-off.bat`。

**9. 端口 6800 被占用？**
`conf\aria2.log` 里会有 `Failed to bind` 之类的报错。换端口见上一条。

**10. 怎么彻底卸载？**
双击 `uninstall.bat` 清理自启项和快捷方式，然后直接删掉整个文件夹。
已下载的文件在 `Downloads` 里，删之前自己确认。

**11. 杀毒软件报毒？**
`aria2c.exe` 是 aria2 官方构建（GPLv2），部分杀软对「带 RPC 服务的下载器」比较敏感，属误报。
介意的话可以自行到 https://github.com/aria2/aria2/releases 下载官方版本替换，配置文件不用动。

## 五、安全说明

- RPC 只监听 `127.0.0.1`（`rpc-listen-all=false`），局域网内其它机器连不上
- 每次安装都会生成新的随机密钥，写在 `conf\aria2.conf` 的 `rpc-secret=`
- 把这份压缩包分享给别人时，对方运行 `install.bat` 会生成**他自己的**密钥，互不影响
- 不要把自己已安装好的 `conf\aria2.conf` 发给别人（里面是你的密钥，虽然只对本机有效）
